# NEXORA ERP - Frontend (Next.js 16 + React 19 + Tailwind CSS)

Modern fullstack Enterprise Resource Planning dashboard frontend built with Next.js and Lucide Icons, connected to the Laravel API backend.

## Features
- **Dashboard**: Executive KPI overview, monthly revenue area charts, sales channel distribution
- **Sales Module**: Real-time order creation, invoice generation, status tracking, payment methods (Cash, Bank transfer, bKash, Card)
- **Inventory & Products**: SKU tracking, warehouse allocation (Dhaka HQ, Chittagong, Sylhet), low stock alerts, quick stock adjustment
- **Customers / CRM**: Client directory, tiers (Enterprise, Business, Standard), lifetime spend tracking
- **Purchases / Supply Chain**: Purchase orders, vendor tracking
- **HR & Staff**: Employee directory, department filtering, role assignments
- **Finance & Invoices**: Accounts receivable, invoice payments
- **Analytics**: Performance charts, margins, conversion rates
- **Settings**: Workspace customization and dark/light appearance

## How to Run
```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Start the Next.js development server
npm run dev
```
Open `http://localhost:3000` in your browser.
